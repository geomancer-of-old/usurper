# Usurper

Usurper is a lab lifecycle manager for disposable VMs. It installs, health-checks and tears down labs, so a single box can be re-used as a clean training ground. 
Each lab is a self-contained directory under labs/. Adding a lab means dropping in a directory — there's no central file to edit.

&#x26A0;&#xFE0F; Labs may be deliberately vulnerable. Only run Usurper on an isolated, disposable VM you control.
